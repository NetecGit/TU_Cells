
# Branch: Cap1

## Objetivos Generales del Capítulo 1.

 
1. Comprender los fundamentos de la Programación Orientada a Objetos (POO) y su aplicación en el desarrollo de software moderno, identificando conceptos clave como clases, objetos, encapsulamiento, herencia y polimorfismo.
2. Analizar los principios fundamentales del desarrollo de aplicaciones web, incluyendo la arquitectura cliente-servidor y el flujo de comunicación mediante el protocolo HTTP.
3. Interpretar solicitudes y respuestas HTTP, reconociendo sus encabezados, métodos (GET, POST, PUT, DELETE, entre otros) y códigos de estado, para entender la interacción entre cliente y servidor.
4. Identificar buenas prácticas en el diseño de APIs, considerando conceptos como idempotencia, manejo de datos en formato JSON y políticas de seguridad como CORS.
5. Aplicar principios de diseño de software, incluyendo patrones de diseño y los principios SOLID, para desarrollar soluciones mantenibles, escalables y reutilizables.
6. Utilizar herramientas esenciales del desarrollo web moderno, tales como editores de código (Visual Studio Code), entornos de ejecución (Node.js) y lenguajes como JavaScript.
7. Gestionar el control de versiones del código fuente, utilizando Git y plataformas como Bitbucket, para facilitar la colaboración y el seguimiento de cambios en proyectos de desarrollo.
