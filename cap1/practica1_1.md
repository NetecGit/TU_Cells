## Tabla de ayuda


| Concepto                | Descripción                                                                     |
| ----------------------- | ------------------------------------------------------------------------------- |
| Polimorfismo            | Permite que un mismo método tenga diferentes comportamientos según el objeto.   |
| Objeto                  | Instancia concreta de una clase.                                                |
| Herencia                | Permite crear nuevas clases a partir de otras reutilizando atributos y métodos. |
| Abstracción             | Enfocarse solo en lo esencial, ocultando detalles innecesarios.                 |
| Constructor             | Método especial que inicializa un objeto al crearse.                            |
| Encapsulamiento         | Protege los datos ocultándolos y controlando su acceso.                         |
| Relaciones entre clases | Formas en que las clases interactúan (uso, agregación, composición, herencia).  |
| Clase                   | Plantilla o modelo para crear objetos.                                          |
| Acoplamiento            | Nivel de dependencia entre clases.                                              |
| Cohesión                | Qué tan enfocada está una clase en una sola responsabilidad.                    |
| Clase abstracta         | Clase que no se puede instanciar y sirve como base para otras.                  |
